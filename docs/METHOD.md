# Learning Method

This document explains the rationale behind the harness. It is reference material, not required daily context.

## Goal-driven learning

The target is independent English performance in a real context, not a polished AI-assisted artifact.

```text
real outcome → baseline by skill → gap and time budget
→ cycle direction → weekly sessions → smallest next task
→ input and production → retrieval and feedback
→ delayed recall or transfer → updated state → weekly adjustment
```

“Improve my English” is a reason, not an actionable goal. A usable goal names the context, observable task, conditions, quality threshold, deadline, and comparable evidence. The cycle gives direction; the weekly session plan turns that direction into work; the next action removes ambiguity today.

## Evidence before labels

Listening, reading, speaking, writing, and receptive/productive vocabulary can develop unevenly. Diagnostic starts with manageable work and changes one difficulty dimension at a time. A practical CEFR-style range is only a compact description of saved evidence, never certification.

Environment limitations are also evidence about measurement, not the learner. If audio is unavailable, listening remains unknown while a provisional plan continues from available skills.

Independent evidence includes raw diagnostic samples, unaided attempts, learner retries, later recall, and changed-context transfer. Explanations, hints, model answers, visible-source repetition, and AI rewrites do not show independent ability.

## Acquisition and performance

New language needs a small comprehensible input before retrieval:

```text
understand → close source → retrieve or use
```

Practised language needs learner performance before correction:

```text
unaided attempt → self-noticing → bounded feedback → learner retry
```

Feedback targets the two or three issues most likely to improve task completion, meaning, organization, or usable language. Normal practice does not wholesale-rewrite the learner's answer.

## Vocabulary as shared infrastructure

Vocabulary connects the four skills rather than acting as a fifth subject. Useful items are usually chunks, collocations, frames, or domain phrases that recur, block meaning, combine usefully, or will be needed soon.

Knowledge is evidenced by recognition in speech, understanding in a new text, retrieval in speaking, appropriate written use, and delayed transfer. `learner/VOCABULARY.md` owns that knowledge record; `reviews/QUEUE.md` owns when and how it will be tested.

A good review cue creates one closed-source decision rather than familiarity with a long card. Important sense, pronunciation, collocation, and register claims need a learner dictionary, trusted source, or real corpus evidence; plausible AI wording alone is not verification.

When vocabulary is a bottleneck, organize a goal-linked weekly theme with repeated retrieval and one integrated speaking or writing output. Tracking items without requiring this production is metadata, not a vocabulary learning cycle.

## Material, retention, and adjustment

Material is part of the learning decision, not homework for the learner to search. Select a specific lawful item or excerpt whose goal relevance, level, session time, language value, evidence availability, and learner interest make it challenging but finishable.

If almost everything is unknown, simplify. If gist is clear but important details fail, focused work is often useful. If everything is trivial, raise one variable such as speed, length, support, topic, interaction, or time pressure.

Intensive work is short and inspectable; extensive exposure is longer and meaning-focused. Both matter.

Consumption time is not comprehension evidence. Intensive listening and reading preserve first-pass meaning, important gaps, reconstruction or retelling, and level-appropriate reasoning evidence. Later parallel material tests whether the capability transfers beyond memory of the original.

Review intervals respond to performance rather than a universal calendar. Weekly review examines completion, quality, retention, transfer, errors, material fit, and energy, then changes one important variable instead of redesigning the whole system.

## Privacy

Keep credentials, sensitive recordings or transcripts, customer data, and unredacted employer information out of the repository. Sanitize real examples before practice.
