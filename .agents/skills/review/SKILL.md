# Review

Read `AGENTS.md`, `learner/PROGRESS.md`, `learner/VOCABULARY.md`, `learner/ERRORS.md`, and `reviews/QUEUE.md`. Select one due item unless the learner chooses another.

If the queue has no item with source evidence, say so briefly and do not invent a delayed review. Offer a fresh unaided practice task, or an assessment if the learner wants one. Only schedule a future review after real learner evidence exists.

Present the recall or transfer task without revealing the previous answer, target phrasing, or correction notes. A transfer task must preserve the capability while changing the scenario, topic, audience, or wording. For vocabulary, ask for recognition from audio or text, closed-source retrieval, or use in a new context; do not reduce a chunk review to a translation quiz.

Request an unaided attempt first. Give brief feedback only after the attempt and learner self-noticing. Capture useful evidence in a dated session record when the interaction is meaningful.

Update the selected queue item in plain language: complete it, defer it with a reason, or replace it with a better next review. If retrieval fails, add a nearer, simpler recall prompt; do not mark an error resolved from assisted output.
