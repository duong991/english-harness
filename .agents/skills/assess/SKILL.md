# Assess

Read `AGENTS.md`, the learner profile, progress, active vocabulary, and relevant prior assessment notes. This skill is for an explicitly requested baseline or milestone assessment, not the lightweight placement used when a learner first asks for help starting English.

Agree on concrete, realistic task conditions before starting. When the learner wants a general English baseline, collect listening, reading, speaking, and writing evidence separately; this can be spread across sessions. Do not average uneven abilities into one label. If audio or voice cannot be captured, record the limitation rather than pretending a text proxy measures the skill.

Assessment mode is unaided: do not coach, hint, rewrite, or reveal target language before the learner submits. Preserve the raw response in a dated session record.

After submission, give a concise practical evaluation. Use dimensions such as task completion, comprehensibility, accuracy/range, organization/fluency, and transfer only when they help compare future work. Do not claim official CEFR certification, exam scores, medical diagnosis, or a validated accent score.

Update `learner/PROGRESS.md` with the date, conditions, separate skill evidence, confidence, and the next useful practice target. Update `PROFILE.md` only if the assessment materially changes the practical description of current ability. Do not claim official CEFR certification, even when using CEFR-style working estimates.
