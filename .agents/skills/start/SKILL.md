# Start

Read `AGENTS.md`, `docs/WORKFLOW.md`, `docs/LEARNING_PATH.md`, and all authoritative learner files. Check whether the learner already has enough evidence to resume ordinary study. If they do, use the `study` skill instead.

Explain briefly that this is not an exam. Its purpose is to identify what English should enable for this learner, then choose a good starting point. Goal discovery and placement may be spread across several sessions.

## Discover the primary purpose first

Before choosing a level, material, or skill priority, identify the learner's main reason for learning English. Start with one direct question, for example:

> What do you most want English to help you do in the next few months?

Use at most one or two short follow-ups when needed to make the purpose actionable:

- Which real situations matter most, and who is involved?
- What does a successful outcome look like, and is there a deadline or recurring need?
- Which channel matters in those situations: listening, reading, speaking, writing, or a mix?

Do not assume a profession, native language, domain, or priority skill. The learner may name work, study, an exam, travel, relocation, relationships, media, a hobby, or more than one purpose. When there are several goals, ask which one is primary for the next learning cycle; keep the others as secondary contexts.

Update `learner/PROFILE.md` with the observable goal, primary situations, priorities when known, and preferences that materially affect lesson design. If the profile already contains information, confirm it rather than overwriting it. Do not begin placement with a task that presumes a goal the learner has not chosen.

## Collect a practical profile

Gather short, raw evidence for listening, reading, speaking, and writing over one or more sessions. Use familiar contexts and material that is manageable enough to complete. When possible, make the sample relevant to the primary purpose without making it too hard for the learner's current ability.

- **Listening:** use actual short permitted audio with a reliable transcript. First ask for gist and selected details without the transcript. If audio is unavailable, defer this evidence; do not use written text as a substitute.
- **Reading:** give a short, level-appropriate text and ask for the main idea and a small number of details or a response.
- **Speaking:** ask for a brief unscripted introduction or familiar-topic response, preferably a recording. If only typed text is possible, label it a limited proxy rather than full speaking evidence.
- **Writing:** ask for a short unaided message or description with a real audience and purpose.

Do not require all four samples in one sitting. Preserve each raw sample in a meaningful dated session record. Record what the learner can do, the main barrier, and confidence in `learner/PROGRESS.md`; use practical ranges only when evidence supports them, and never claim certification.

## Start learning immediately

After the first sample, do not leave a beginner with only a diagnosis. Choose a tiny input from the learner's chosen context: usually three to five high-value chunks, a short dialogue, or a short accessible audio or text. Explain only enough to make the input comprehensible. Then remove the source and ask for recognition, retrieval, or use in a related familiar situation.

Keep any active chunks in `learner/VOCABULARY.md`. If the learner completes a performance attempt, follow the normal self-noticing, bounded-feedback, learner-retry loop. Add a delayed recall or transfer prompt only when there is source evidence worth revisiting.

## Hand off cleanly

Update `learner/PROGRESS.md` with the primary purpose, current phase, available skill evidence, priority, current bottleneck, and smallest next task. Once there is enough evidence to select goal- and level-appropriate material, use the `study` skill for ordinary sessions. Use `assess` only if the learner explicitly requests a controlled assessment.
